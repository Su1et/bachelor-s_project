# LogiCore OMS — веб-орієнтована CRM/ERP-система для логістично-складської компанії

Система призначена для автоматизації внутрішніх операційних процесів логістично-складської компанії, яка працює з постачальниками, товарами, складами, запасами, міжскладськими переміщеннями, замовленнями та управлінською аналітикою.

## Реалізований функціонал

- Авторизація користувачів через JWT.
- Рольова модель: адміністратор, менеджер, працівник складу, керівник/аналітик, оператор.
- Реальне розмежування доступу в меню, формах і діях редагування/видалення.
- Модуль користувачів і ролей.
- Модуль постачальників.
- Модуль складів із адресою, координатами, статусом і відповідальною особою.
- Карта складів на основі OpenStreetMap.
- Модуль товарів.
- Модуль запасів.
- Модуль руху запасів з операціями: надходження, списання, переміщення, повернення.
- Автоматичний розрахунок відстані та орієнтовного часу переміщення між складами за координатами.
- Модуль замовлень.
- Розширений дашборд з KPI, графіками й критичними залишками.

## Унікальний функціонал

Система поєднує базові можливості CRM/ERP/WMS для управління товарами, складами, постачальниками, запасами й замовленнями з логістичними функціями: картою складів, розрахунком часу переміщення між складами та управлінським дашбордом із графіками.

## Технології

Backend:
- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT

Frontend:
- React
- Vite
- Axios
- React Router
- CSS-графіки без додаткових бібліотек

## Запуск backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.db.seed
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Якщо база вже є, команда `python -m app.db.seed` перезапише її демонстраційними даними.

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Відкрити у браузері адресу, яку покаже Vite, зазвичай:

```text
http://127.0.0.1:5173
```

## Ролі користувачів

| Роль | Повноваження |
|---|---|
| Адміністратор | Повний доступ до всіх модулів, користувачів, ролей, створення, редагування, видалення. |
| Менеджер | Товари, постачальники, склади, запаси, рух запасів, замовлення, аналітика. |
| Працівник складу | Склади, залишки, рух запасів, приймання, списання, переміщення. |
| Керівник / аналітик | Дашборд, KPI, звіти, перегляд складів, запасів, замовлень без редагування критичних даних. |
| Оператор | Базова робота із замовленнями та переглядом товарів. |
